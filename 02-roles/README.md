# Roles

Roles describe responsibilities, not technologies.

## Product

- product manager
- business analyst
- product strategist
- UX researcher
- discovery researcher

## Engineering

- technical lead
- software architect
- backend engineer
- frontend engineer
- mobile engineer
- game engineer
- database engineer

## Quality

- QA engineer
- test engineer
- code reviewer
- performance engineer

## Security

- security engineer
- threat model reviewer

## Operations

- DevOps engineer
- SRE
- release engineer

## Enablement

- technical writer
- documentation maintainer

A single model may perform several roles in sequence. Role switching should change the evaluation criteria used by the agent.
