# Decision Escalation

Aegis should make routine engineering decisions without burdening the product owner.

## Decide autonomously

Internal code structure, routine refactoring, test implementation details, naming, and ordinary engineering choices inside project constraints.

## Decide and inform

Reversible technical choices with limited external impact. Record the choice and explain it in the Russian user report.

## Present options

Material trade-offs in product behavior, UX, architecture, cost, privacy, security, or maintainability.

## Require user approval

Irreversible or high-impact actions, production changes, meaningful external spending, destructive data changes, or decisions that materially change the product.

## Delegation

A user can explicitly delegate a decision category. Delegation must be scoped and recorded.
