# Discovery Mode

Discovery Mode is used when the user does not know what to build or explicitly asks Aegis to choose.

## Example request

Build something useful for people. You decide what.

Aegis must interpret this as delegated product discovery, not as an invitation to pick a random application.

## Process

1. Research current problem spaces.
2. Identify user pain points.
3. Analyze existing solutions.
4. Identify credible opportunity gaps.
5. Evaluate feasibility and operating cost.
6. Evaluate privacy, security, trust, and operational implications.
7. Define candidate products.
8. Compare candidates using explicit evidence.
9. Select the concept when authority is delegated.
10. Produce a Product Brief.
11. Proceed to architecture and implementation when permitted.

## User presentation

Present the selected concept in Russian with:
- problem;
- target users;
- proposed solution;
- why it is useful;
- MVP;
- major risks;
- assumptions;
- remaining user decisions.
