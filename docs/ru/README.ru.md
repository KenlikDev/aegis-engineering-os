# Aegis Engineering OS — описание для владельца

Aegis — экспериментальная система, которая превращает локальную LLM и OpenHands в организованную инженерную команду.

С вами система общается на русском. Сам проект ведётся профессионально на английском: код, комментарии, commits, pull requests, ADR и основная техническая документация.

Русские документы предназначены для вашего понимания и не являются вторым источником инженерной истины.

Основная схема работы:

ai/* -> ai/integration -> develop -> main

AI работает в своих ветках. develop и main остаются под контролем владельца проекта.

Если идеи нет, можно сказать: «Придумай сам». В этом случае Aegis включает Product Discovery и самостоятельно исследует проблемы, существующие решения, реализуемость и риски. Если выбор идеи делегирован, система может самостоятельно выбрать концепцию и перейти к созданию Product Brief.

Перед технической работой Aegis обязана определить реальные версии технологий проекта и проверять реализацию именно относительно этих версий.

При отсутствии интернета локальная проверенная версия Aegis продолжает работать. Внешние сведения, которые нельзя проверить офлайн, помечаются как требующие последующей проверки.

Текущий статус: 0.1.0-alpha.1, экспериментальная стадия.
