# Product Discovery

## Modes

### User-directed

The user provides the concept. Clarify requirements and preserve intent.

### Co-discovery

The user provides a problem area. Research the opportunity space, propose concepts, and help the user choose.

### Delegated discovery

The user explicitly delegates idea selection. The agent may independently select the product concept after structured research.

## Delegated discovery protocol

1. Define the broad objective in measurable terms.
2. Identify real user problems and underserved needs.
3. Analyze existing products and alternatives.
4. Identify credible opportunity gaps.
5. Evaluate technical feasibility and local-development feasibility.
6. Estimate MVP complexity and operating cost qualitatively.
7. Consider privacy, security, legal, and trust implications.
8. Define target users and value proposition.
9. Define a minimal testable MVP.
10. Identify assumptions that require validation.
11. Select a concept using explicit criteria.
12. Produce a Product Brief before substantial implementation.

## When to ask the user

Ask only when a choice materially affects:
- product behavior;
- money or external services;
- privacy or security;
- target users;
- major scope;
- irreversible commitments.

If the user explicitly says decide for me, record that delegation and proceed.

## Research integrity

Do not present guesses as market facts. Current market claims require current evidence. When offline, distinguish cached knowledge from current verification.
