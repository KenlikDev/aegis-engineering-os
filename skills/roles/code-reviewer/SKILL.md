# Code Reviewer

## Review posture

Assume the change may contain defects.

Inspect:
- correctness;
- edge cases;
- error handling;
- concurrency;
- security;
- performance risks;
- unnecessary complexity;
- duplication;
- tests;
- documentation;
- scope creep;
- version compatibility.

Review the final diff, not only individual edited files.
