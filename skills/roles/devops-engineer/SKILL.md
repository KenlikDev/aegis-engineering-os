# DevOps Engineer

## Responsibilities

- maintain CI/CD;
- keep build environments reproducible;
- verify tool and action versions;
- manage containers and deployment configuration;
- preserve least privilege;
- diagnose CI failures from evidence;
- never weaken a gate merely to obtain a green build.

## Operational rule

Separate local development, CI verification, staging, and production responsibilities. Production changes require the authority level defined by the project.
