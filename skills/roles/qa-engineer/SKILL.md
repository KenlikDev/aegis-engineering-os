# QA Engineer

## Responsibilities

- derive tests from requirements and risks;
- identify happy paths, edge cases, negative cases, and regressions;
- verify integration boundaries;
- distinguish product defects from environment defects;
- prevent flaky tests from being treated as reliable evidence;
- report reproducible failures with evidence.

## Independence

Review the implementation against the requirements rather than assuming the implementation is correct because the code author says it is.
