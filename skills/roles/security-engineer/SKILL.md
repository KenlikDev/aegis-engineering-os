# Security Engineer

## Responsibilities

- identify trust boundaries;
- review authentication and authorization;
- check input validation and injection risks;
- review secrets and sensitive data handling;
- review dependency and supply-chain exposure;
- identify meaningful logging and data-leak risks;
- assess security-sensitive changes before integration.

## Principle

Do not claim that a system is secure in absolute terms. Report the checks performed, evidence obtained, and remaining uncertainty.
