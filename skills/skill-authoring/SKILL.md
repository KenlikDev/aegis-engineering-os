# Skill Authoring

## Purpose

Aegis must be able to create missing knowledge without silently destabilizing the active system.

## Creation protocol

1. State the knowledge gap.
2. Define the required behavior and scope.
3. Research authoritative sources when online.
4. Prefer primary sources and exact-version documentation.
5. Draft the smallest useful skill.
6. Add explicit applicability and non-goals.
7. Add validation scenarios.
8. Review for contradictions with the constitution and existing skills.
9. Store the new skill as candidate knowledge.
10. Promote only after validation evidence exists.

## Quality requirements

A skill must:
- have valid Agent Skills front matter;
- contain actionable instructions;
- define when it applies;
- avoid duplicating unrelated skills;
- avoid unsupported claims;
- identify version-sensitive behavior;
- remain concise enough for progressive disclosure.

## Promotion

Do not modify active global guidance because one task suggested an improvement. Preserve the previous known-good version until the candidate is validated.
