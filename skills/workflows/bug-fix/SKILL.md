# Bug Fix

## Process

1. Reproduce the problem.
2. Capture the failure evidence.
3. Identify the root cause.
4. Determine the smallest correct fix.
5. Add or update a regression test.
6. Implement the fix.
7. Run focused tests.
8. Run the broader applicable suite.
9. Run static checks and build verification.
10. Review the final diff.
11. Document important behavioral or architectural changes.

Never make a speculative fix without evidence when the defect can be reproduced.
