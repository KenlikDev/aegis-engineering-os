# Bug Fix

## Process

1. Identify or create the authoritative work item.
2. Record the reported behavior, impact, reproduction information, and acceptance criteria.
3. Reproduce the problem.
4. Capture the failure evidence.
5. Identify the root cause.
6. Determine the smallest correct fix.
7. Add or update a regression test.
8. Implement the fix.
9. Run focused tests.
10. Run the broader applicable suite.
11. Run static checks and build verification.
12. Perform an independent review when required.
13. Review the final diff and delivery links.
14. Update the work item with evidence, status, risks, and final outcome.

Never make a speculative fix without evidence when the defect can be reproduced.
