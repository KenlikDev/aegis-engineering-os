# Feature Implementation

## Process

1. Validate requirements and acceptance criteria.
2. Run project discovery.
3. Verify exact technology versions.
4. Select required roles and skills.
5. Create or update the implementation plan.
6. Create an ai/* task branch.
7. Implement in small coherent changes.
8. Add or update tests.
9. Run applicable quality gates.
10. Perform an independent review.
11. Update documentation and ADRs where required.
12. Review Git history and final diff.
13. Push a clean verified checkpoint and create/update the PR.

Do not broaden scope without recording the reason and impact.
