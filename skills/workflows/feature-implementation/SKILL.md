# Feature Implementation

## Process

1. Validate requirements and acceptance criteria.
2. Run project discovery.
3. Verify exact technology versions.
4. Select required roles and skills.
5. Create or reuse the authoritative work item.
6. Define scope, non-goals, dependencies, risks, and verification plan on the work item.
7. Create or update the implementation plan.
8. Create an ai/* task branch associated with the work item.
9. Implement in small coherent changes.
10. Add or update tests.
11. Run applicable quality gates.
12. Perform an independent review.
13. Update documentation and ADRs where required.
14. Review Git history and final diff.
15. Push a clean verified checkpoint and create/update the PR.
16. Update the work item with material progress, verification evidence, links, and final status.

Do not broaden scope without recording the reason and impact. Independent follow-up work should receive its own work item.
